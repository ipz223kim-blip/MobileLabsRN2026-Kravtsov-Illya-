1) Чим відрізняється FlatList від ScrollView?
FlatList показує лише видимі користувачу об'єкти в той же час ScrollView ж відображає всі елементи.
2) Що таке віртуалізація списків?
Це механізм опитимізацї ,щоб не перевантажувати пам'ять : відображаються лише видимі елементи,невидимі компоненти видаляються, та перевикористовуються для перекрутки
3) Як здійснюється передача параметрів між екранами?
Передача параметрів між екранами здійснюється за допомогою методу navigation.navigate(). Дані передаються другим параметром функції, а на цільовому екрані отримуються через об’єкт route.params.
4) Що таке вкладена навігація?
Це структура, у якій один навігатор містить інший.
5) У яких випадках застосовується SectionList?
Коли потрібно відобразити групованих даних, для показу заголовку і набору елементів.
